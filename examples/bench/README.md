# Bench example: cel-js

`cel-js.bundle` is the unmodified git history of
[marcbachmann/cel-js](https://github.com/marcbachmann/cel-js) (MIT License,
© Marc Bachmann) up to `86cd972`, vendored so mining runs offline.

```sh
cd examples/bench
sluice bench mine          # validates fail-to-pass tasks in no-network containers
sluice bench run           # oracle vs first-file (scripted) agents
```

Add real agents to `bench.yaml` (examples are commented in it). The
`first-file` agent reports a **simulated** cost so cost aggregation is testable
without calling a model.

## Go and .NET: textkit

`go-textkit.bundle` and `dotnet-textkit.bundle` are small **synthetic**
repositories generated by `synth/make-repos.mjs` (fixed authors and dates, so
the commit shas are reproducible: `node synth/make-repos.mjs <dir> --bundle`).
Each has a few feature/fix commits that add source and tests and an external
dependency (`github.com/google/go-cmp`; `Humanizer.Core` + xunit).

```sh
sluice bench mine -c go.bench.yaml       # 4 tasks
sluice bench run  -c go.bench.yaml
sluice bench mine -c dotnet.bench.yaml   # 4 tasks
sluice bench run  -c dotnet.bench.yaml
```

The configs set no image, test command or test regex: they default from the
detected toolchain. Dependencies are fetched once by the prepare step (network
at image build time only; the pinned `go.sum` / exact package versions keep it
reproducible) and every test run stays offline. See
[docs/guide/bench.md](../../docs/guide/bench.md#go-and-net).
